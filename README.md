# ChatooAi – WhatsApp AI Chatbot SaaS

ChatooAi is a complete SaaS solution built with **Next.js** (frontend) and **Express.js** (backend).  
It lets you create and manage unlimited **AI-powered WhatsApp chatbots** with no need for the official WhatsApp API.  

⚡️ **Highlights**:
- No official WhatsApp API required (simple QR code login).  
- Free to run at small scale using **open-source AI models**.  
- Supports GPT-4, GPT-3.5, Claude, and self-hosted AI.  
- Complete SaaS system: authentication, subscriptions, and user management.
